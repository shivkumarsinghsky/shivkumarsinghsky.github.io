# shivkumarsinghsky.github.io

Personal site of **Shiv Kumar**, Software Architect: https://shivkumarsinghsky.github.io/

A single static page (`index.html`, generated by `build.py`) served by GitHub Pages, listing my open-source architecture
portfolio. It includes search metadata (title, description, Open Graph) and schema.org `Person`
structured data, plus `sitemap.xml` and `robots.txt` for search engines.

To change content, edit the project list in `build.py`, run `python3 build.py`, then push to `main`.
